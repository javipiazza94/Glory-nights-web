# Avances - Jueves, 26 de Febrero de 2026

## 1. ⚙️ Auditoría y Estabilización de Base de Datos
- Hemos activado y fortalecido las reglas de las **claves foráneas** (`PRAGMA foreign_keys = ON`) tanto en local como en producción (Turso).
- Implementamos el borrado seguro en modo cascada (`ON DELETE SET NULL`), lo que significa que si en el futuro borras una Banda o una Sala desde el Dashboard, los conciertos asociados no romperán la web, sino que se quedarán desvinculados de forma controlada.
- Sincronizamos internamente las reseñas para pre-vincular usuarios y conciertos automáticamente en el panel.

## 2. 📧 Reparación del Auto-Email (Newsletter)
- Arreglamos el bug crítico que impedía que se enviara el correo de bienvenida a los nuevos suscriptores de la newsletter en la versión de desarrollo desplegada en Vercel, solucionando el problema del paso de las variables de entorno.

## 3. 🎨 Rediseño Visual Premium (Tarjetas Horizontales)
- Cambiamos radicalmente el diseño de las páginas públicas de **Conciertos (`/conciertos`)** y **Artistas (`/artistas`)**.
- Pasaron de ser una "rejilla" estilo tablero a una **lista de tarjetas horizontales** muy limpias, consistentes y simétricas con el estilo profesional de la página de Salas (`/venues`).

## 4. 📍 Filtro Inteligente de Ciudades
- Implementamos un nuevo **menú desplegable** en la página principal de conciertos para que los usuarios puedan **filtrar por provincia**.
- El sistema extrae automáticamente y en tiempo real las ciudades desde la base de datos (con una corrección para que siempre sea visible incluso si solo se ha registrado una ciudad).

## 5. 📱 Botones para Compartir y Viralización
- Integramos la **Web Share API nativa** para el nuevo botón "Compartir" de las tarjetas de los conciertos (lanza directamente WhatsApp, Instagram u otras opciones nativas del móvil).
- Añadimos la función **"Añadir al Calendario"**: con un clic crea el evento en Google Calendar usando la hora, sala y detalles pre-parametrizados.
